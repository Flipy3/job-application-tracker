# Job Application Tracker

Job Application Tracker is a Next.js application for tracking job applications.

Current status: Milestone 2C supports Supabase authentication plus Dashboard
Create, Read, Update, and Delete for job records, with polished Dashboard
statistics, status styling, job cards, and empty state.

## Tech Stack

- Next.js
- TypeScript
- App Router
- Tailwind CSS
- ESLint

## Development

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open http://localhost:3000.

Useful local routes:

- `/login`
- `/signup`
- `/dashboard`
